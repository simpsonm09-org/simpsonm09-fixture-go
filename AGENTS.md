# simpsonm09-fixture-go working agreements

A layered Go item CRUD service built on Gin. It is the Go fixture for the fleet standard.

## Ground rules

- Business logic lives in `internal/item/service/` and works in `domain.Item`. The handler never touches the store and the service never sees a DTO. Only `internal/item/api/mapper.go` bridges DTOs and the domain; only the store adapter bridges the port and its records.
- `docs/openapi.json` is generated. Annotate the handler and the DTOs, run `just spec`, and never hand-edit the document. A test fails when the committed document drifts.
- The store is in memory. A restart discards items and restores the three dev seeds.
- No secret, credential, or machine path is committed.

## Commands

- `just install`, `just lint`, `just lint-fix`, `just aislop`, `just test`, `just coverage`, `just spec`, `just serve`, `just verify`, `just prune`.

## Repo facts

- Language and toolchain: Go 1.27, Gin, pinned in `mise.toml`. `golangci-lint` and `gofmt` run through Flint from `.github/config`.
- Tests: the standard `testing` package for unit tests and `net/http/httptest` for integration tests against the real router.
- Data: no database. `internal/item/store/in_memory.go` holds a map and seeds three items on construction.
- Domain: `GET`, `POST`, `PUT`, and `DELETE` over `/items`. Reads, updates, and deletes of an unknown id return `domain.NotFoundError`, which the handler maps to a 404 `application/problem+json` body.
- Contracts: `docs/openapi.json` is generated by `swaggo/swag` through `internal/openapi`. `swag` emits OpenAPI 3.1; the generator then types the optional `description` as a nullable string and serves error responses as `application/problem+json`. Regenerate it with `just spec`.
- Coverage: `just coverage` runs `go test ./... -coverprofile=coverage/cover.out` and `scripts/coverprofile-to-lcov.mjs` writes `coverage/lcov.info`.
- Docs: `docs/README.md` indexes the architecture, the items feature, and the OpenAPI contract.
